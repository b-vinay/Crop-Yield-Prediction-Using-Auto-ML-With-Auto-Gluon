Crop Yield Prediction Using Auto ML With AutoGluon
Overview

This project focuses on predicting agricultural crop yield using Machine Learning and Automated Machine Learning (AutoML). The system is built using AutoGluon, an open-source AutoML framework designed to automate model training, feature engineering, model selection, and hyperparameter optimization. AutoGluon is designed for tabular data and uses model ensembling and stacking to improve predictive accuracy.

The primary objective of this project is to help farmers, researchers, and agricultural planners estimate crop yield based on environmental and agricultural factors. By analyzing historical agricultural data, the system generates accurate yield predictions that can support better farming decisions.

Problem Statement

Agricultural productivity depends on multiple factors such as:

Rainfall
Temperature
Soil properties
Crop type
Area under cultivation
Seasonal conditions

Traditional yield estimation methods are often time-consuming and less accurate. This project uses AutoML to automatically identify the best-performing machine learning models for crop yield prediction.

Support data-driven decision-making in agriculture.

Workflow
1. Data Collection

Agricultural datasets containing crop production data, climatic conditions, and soil parameters are collected.

2. Data Preprocessing

The dataset is cleaned by:

Handling missing values
Removing duplicates
Encoding categorical features
Feature scaling
3. Model Training

AutoGluon automatically:

Tests multiple machine learning algorithms
Performs feature engineering
Tunes hyperparameters
Builds stacked ensemble models
4. Prediction

The trained model predicts crop yield based on user-provided agricultural inputs.
